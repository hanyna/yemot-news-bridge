# yemot-news-bridge

מחבר בין **Telegram Popup** (ה-API `/api/messages`) לבין קו הטלפון ב**ימות המשיח**.
רץ ב-GitHub Actions, שולף את 10 ההודעות האחרונות מכל הערוצים, ושולח כל
הודעה לקובץ TTS נפרד בשלוחה 1 (`001.tts` עד `010.tts`), בפורמט:
"<שם הערוץ>, בשעה <שעה>. <תוכן ההודעה>".

> ⚠️ קובץ TTS בימות המשיח מוגבל לכ-1,300 תווים — לכן כל הודעה בקובץ משלה,
> ומוגבלת ל-1,000 תווים. הודעה ארוכה יותר נחתכת בסוף מילה.
>
> ⚠️ השלוחה צריכה להיות מסוג השמעת קבצים (playfile), והקבצים `001`–`010`
> בה שמורים לגשר — אל תשים בה קבצים אחרים באותם שמות.

## הקמה

1. **צור ריפו חדש בגיטהאב** (ציבורי או פרטי — לא משנה) ותעלה אליו את כל
   הקבצים בתיקייה הזו (`go.mod`, `main.go`, `render.yaml`, `README.md`).

2. **ב-Render:** New → Blueprint → תחבר לריפו החדש. Render יזהה את
   `render.yaml` ויציע ליצור שירות מסוג Cron Job בשם `yemot-news-bridge`.

3. **מלא שני משתני סביבה סודיים** (בעמוד Environment של השירות ב-Render,
   בדיוק כמו שעשית עבור `telegram-popup`):
   - `TGPOPUP_KEY` — אותו מפתח שכבר יש לך ב-Environment של `telegram-popup`
   - `YEMOT_API_KEY` — המפתח הקבוע שנוצר בעמוד "מפתחות גישה" בימות המשיח
     (חייב הרשאה ל-`/api/UploadTextFile` ברשימה הלבנה של המפתח)

4. שאר המשתנים (`YEMOT_NUMBER`, `YEMOT_EXT`, `YEMOT_FILE`) כבר מוגדרים
   בברירת מחדל ל-0772263731 / שלוחה 1 / קובץ 001.tts — אפשר לשנות
   ב-`render.yaml` אם תרצה שלוחה או קובץ אחרים.

## מה זה עושה בפועל, כל דקה
1. קורא ל-`https://telegram-popup.onrender.com/api/messages?k=...`
2. לוקח את ההודעה הראשונה ברשימה (החדשה ביותר, מכל הערוצים)
3. שולח את הטקסט המלא שלה (`contents=...`) ל:
   `https://www.call2all.co.il/ym/api/UploadTextFile?token=<מספר>:<סיסמה>&what=ivr2:/1/001.tts&contents=...`
4. ימות המשיח משמיע את הטקסט בהקראת TTS למי שמתקשר לקו ובוחר בשלוחה 1

## הערה — הודעות זהות
אם אין הודעה חדשה מאז הריצה הקודמת, הסקריפט עדיין שולח מחדש את אותו טקסט
(פשוט מעדכן את אותו קובץ TTS לאותו תוכן). זה לא גורם נזק, רק מיותר. אם
בעתיד תרצה לשלוח רק כשיש שינוי אמיתי, אפשר להוסיף שמירת ה-ID האחרון
במקום חיצוני (Render Key-Value / קובץ ב-Disk בתוכנית בתשלום) — נעדכן
את זה בהמשך אם ירצה.

## בדיקה ידנית מקומית (לא חובה)
```
export TGPOPUP_KEY=...
export YEMOT_API_KEY=...
go run .
```
