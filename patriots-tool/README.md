# הפטריוטים המלא — כלי למחשב

מוריד כל לילה את **התוכנית המלאה המוכנה** של "הפטריוטים" מיוטיוב (בלי פרסומות,
בלי קפיצות), ומעלה אותה לקו בשלוחה 3/3 **במקום ההקלטה מהשידור** שהגשר העלה.

## למה צריך מחשב
יוטיוב ואתר הצפייה של ערוץ 14 חוסמים את השרתים של GitHub שהגשר רץ עליהם, אבל
לא מחשב ביתי בישראל. לכן ההורדה המוכנה נעשית מהמחשב שלך — דרך אותם כלים
(yt-dlp + ffmpeg) שמוריד השירים כבר מתקין ומריץ, כולל התמיכה בנטפרי/רימון.

## התקנה (פעם אחת)
1. פתחו את התיקייה שקיבלתם.
2. לחצו קליק ימני על **`התקנה.bat`** → "הפעל כמנהל".
3. הדביקו את **המפתח הקבוע של הקו** (אותו מפתח של הגשר, מעמוד "מפתחות גישה"
   בימות המשיח).
4. הכלי משתמש ב-`yt-dlp` וב-`ffmpeg` ש**מוריד השירים כבר התקין** (אותם כלים,
   שכבר עובדים דרך נטפרי). רק אם הם לא נמצאים — ההתקנה מורידה אותם כגיבוי.
   בסוף נרשמת משימה מתוזמנת.

זהו. מכאן זה אוטומטי.

## איך זה עובד
- המשימה רצה כל לילה ב-**23:40**, ושוב ב-**06:30** כגיבוי.
- היא מוגדרת **להעיר את המחשב מהשינה** (Wake to run). כל עוד המחשב מחובר לחשמל
  ולא כבוי לגמרי — הוא יתעורר, יוריד, ויחזור לישון מעצמו.
- אם באותו לילה התוכנית עדיין לא עלתה ליוטיוב, או שהמחשב היה כבוי — לא נורא:
  נשארת ההקלטה מהשידור שהגשר כבר העלה, והכלי ינסה שוב בהרצה הבאה.
- הכלי מחליף רק פרק שהגשר **כבר סיים** להעלות, כך שאין התנגשות בין השניים.

## הגדרות
אפשר לערוך את הקובץ `patriots.env` שבתיקייה
`%LOCALAPPDATA%\YemotPatriots` (ב-Notepad):
- `YT_COOKIES_BROWSER` — אם ביום מן הימים יוטיוב יבקש אימות ("Sign in to
  confirm"), כתבו שם את הדפדפן שבו אתם מחוברים ליוטיוב: `chrome` / `edge` /
  `firefox`.
- `PATRIOTS_DAYS_BACK` — כמה ימים אחורה לבדוק (ברירת מחדל 2).

## בדיקה ידנית
לחיצה כפולה על `yemot-patriots.exe` בתיקיית ההתקנה מריצה פעם אחת עכשיו
(צריך קובץ `patriots.env` לידו — נוצר בהתקנה).

## הסרה
להרצה ב-PowerShell:
```
Unregister-ScheduledTask -TaskName YemotPatriots -Confirm:$false
```
ולמחוק את התיקייה `%LOCALAPPDATA%\YemotPatriots`.
